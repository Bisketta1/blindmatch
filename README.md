# blindmatch

Blinddejt via vänner: du swipar åt dina vänner, matchmakers chattar och planerar dejten, singlarna får en blind inbjudan.

- Mobilapp: Expo (React Native), testas med Expo Go
- Backend: Supabase (projekt `pdxdbcftaphdonrlpbwy`, eu-north-1, gratisplan)
- Idé, krav och arbetssätt: `docs/original-prompt.md`

## Regler
- Max 10 swipes per dag per vän.
- Matchmakers godkänner dejtförfrågan (tid + plats) innan den skickas till singlarna.
- Hinge-lik profil (roliga frågor, voice notes). Mjuk och mysig känsla.
