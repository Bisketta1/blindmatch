# Council, round 3 (autopilot): architecture, Apple HIG cleanup, reschedule, safety, names

Product: blindmatch, Swedish-first Expo + Supabase app where friends swipe for friends; the two matchmakers plan a blind date; singles get an invite (first name, clues, no photo), confirm, chat on the day. Built so far: swipe with first-yes-wins claims, matches, matchmaker chat, date proposals with address/Maps link/description, invites and acceptance by both singles, countdown, date-day chat with animated quick replies, feedback + thanks + matchmaker card, premium code, demo-account switch, unread badges, match animation, friend profiles, i18n (sv). Design: ivory/espresso/terracotta, Fraunces serif for titles, system font for text, pill buttons, soft shadows.

Current code layout (app/): `app/` = Expo Router screens ((auth), (tabs): index, chats, dates, friends, profile; chat/[id], date-chat/[id], friend/[id], edit-profile, onboarding, privacy). `src/components/` holds 16 mixed components (ui, Icon, Display, DateCard, DateField, Wheel, ChatBubble, ChatInput, QuickReplies, ReplyFlight, FeedbackCard, MatchmakerCard, MatchOverlay, ProfileForm, SwitchProfileSheet, ViewAsBanner). `src/lib/` holds session, supabase, badges, haptics, sound, dates, maps, countdown, ideas, matchmaker, age, photos, notify, useNow. `src/features/swipe/` holds SwipeCard + decision. `src/i18n/sv.json`, `src/theme.ts`, `src/config.ts`. Tests: app/__tests__/logic.test.ts (one file). supabase/migrations 0001-0014, supabase/tests, supabase/functions/demo-login.

Questions (answer all that your lens can speak to; be concrete, decide, do not hedge):

Propose the exact target tree for app/src so that an AI agent can find any code fast: feature folders vs layers, what is shared, where RPC calls and types live, test placement, naming rules, and what the thin route files in app/app should contain. List the move map (old path -> new path) for every current file.
B. APPLE HIG CLEANUP (the "Apple Design" skill, dickwu/apple-design-skill).
